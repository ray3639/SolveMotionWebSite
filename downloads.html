Check compatibility before installing.

These APKs retain the existing Android Debug signing certificate. They use a different certificate from original installations and cannot update an incompatible installation. Replacing an incompatible installation requires a separately authorized uninstall and can erase local app data. Downloading does not uninstall or clear data.

Pharmacy web 134 and its Play internal testing channel are separate from this public APK133. A later device installation or source build does not replace the public download listed here.
