Release Notes

SolveMotion Labs releases stay tied to verified builds, central baselines, Core 12 alignment, and production-style checks. Public language stays truthful: live apps are launchable, review artifacts are labeled, and incomplete surfaces are not promoted.

Download Rules

Access is organized by channel so live web apps, Android artifacts, iOS artifacts, review files, and Core 12 expectations stay clear.

  • Release channel: web app launches are listed only for applications with an approved live web portal.
  • Artifact readiness: Android APK, Android AAB, and iOS IPA links represent governed release artifacts or clearly labeled review artifacts.
  • Mobile and web boundary: mobile artifacts can be available before a web app is approved for launch.
  • Core 12 integration: released surfaces must preserve DomainSignal input, Core DTO output, and render-only application expectations.
  • SolveOura guardrail: SolveOura remains listed as in-progress review artifacts only, with no web app launch until completion and verification.

Download availability should remain aligned with baseline status, release notes, artifact existence, and production verification before a link is promoted.
