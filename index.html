How It Works

Product systems collect domain context, Core 12 reasons over that context, and the apps display the result. The intelligence stays centralized, explainable, and governed.

1. Context

Movement, cognitive, investigation, pharmacology, and recovery workflows collect structured evidence and user context.

2. Structured Input

The app sends structured DomainSignal or approved domain input into Core 12.

3. Core Reasoning

Core 12 owns readiness, confidence, risk, recommendations, missing evidence, reports, trajectory, and governed decision explanation.

4. Governed Output

Immutable output carries reviewable intelligence back to the app for display.

5. Rendered UI

Product screens render Core output and preserve the no-local-computation rule.

6. Release Gate

Release checkpoints, ASCII / NO_BOM checks, route verification, and cross-page audits protect the production website from silent drift.
