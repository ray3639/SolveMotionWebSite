Core 12.0 Architecture Flow

The platform follows a clear operational intelligence contract. Product systems collect domain context, Core 12.0 reasons over that context, and the applications display the result without owning hidden scoring or duplicate decision logic.

1. Domain Context

Movement, cognitive, investigation, pharmacology, and recovery workflows collect structured evidence and user context.

2. DomainSignal Input

The app sends structured DomainSignal or domain DTO input into the Core 12.0 reasoning layer.

3. CoreIntelligenceOrchestrator

CoreIntelligenceOrchestrator owns readiness, confidence, risk, recommendations, missing evidence, reports, trajectory, and governed decision explanation.

4. DTO Output

Immutable DTO output carries reviewable intelligence back to the app for display.

5. Render-Only UI

Product screens render Core output and preserve the no-local-computation rule.

6. Release Gate

Baselines, ASCII / NO_BOM checks, route/content verification, and cross-page audits protect the production website from silent drift.
